Install and run yt-dlp on Windows

October 6, 2026

Download executables

  1. Open a browser.
  2. Navigate to https://github.com/yt-dlp/yt-dlp/releases/latest.
  3. Download the Windows executable yt-dlp.exe.
  4. Navigate to https://github.com/yt-dlp/FFmpeg-Builds/releases.
  5. Click the link win64-gpl.
  6. This will download a file with a name that looks like ffmpeg-N-xxxxxx-yyyyyyyyyy-win64-gpl.zip.
  7. Close your browser.

Create and populate yt-dlp directory

  1. Create a directory C:\yt-dlp.
  2. Copy yt-dlp.exe from your downloads directory into C:\yt-dlp.
  3. Extract the zip file ffmpeg-N-xxxxxx-yyyyyyyyyy-win64-gpl.zip.
  4. From inside the extracted directory's bin subdirectory, copy ffmpeg.exe into C:\yt-dlp.

Add yt-dlp to execution path

  1. In the Windows search box, type environment.
  2. Open the Control Panel at System Properties.
  3. Click Environment Variables.
  4. Select Path.
  5. Click Edit.
  6. Click New.
  7. Add C:\yt-dlp.
  8. Click OK.
  9. Click OK.
  10. Click OK.
  11. Restart your PC (or just log out and log in to your user id again).

Verify installation

  1. In the Windows search box, type cmd.
  2. Open a Command Promp windows.
  3. Enter the command yt-dlp --version.
  4. You should see a version number of the form yyyy.mm.dd.

Run yt-dlp on Windows

  1. In the Windows search box, type cmd.
  2. Open a Command Promp windows.
  3. Change into your Downloads folder with the command cd Downloads.
  4. Enter the command yt-dlp --F <youtube-url> (without the angle brackets).
  5. You should see a list of available format numbers.
  6. Pick the format number that best suits your requirements.
  7. Enter the command yt-dlp --f <your-chosen-format-number> <youtube-url> (without the angle brackets).
