Install Lynx browser on Windows Subsystem for Linux

October 4, 2026

Install Windows Subsystem for Linux (WSL)

Press the Windows Start button.

In the search box, type powershell and press Enter.

From the available options, select Run as Administrator.

In the PowerShell window, enter the command:

wsl --install

This command enables the features necessary to run WSL.

When prompted at the end of the install, restart your PC.

Install Ubuntu

At one point, installing WSL automatically installed Ubuntu, but now it seems you have to install Ubuntu manually.

Again launch PowerShell with Run as Administrator. Then enter the command:

wsl --install -d Ubuntu

When you launch Ubuntu Linux, you will be prompted to create a user account and password.

Now you can launch Ubuntu like any other program from your Windows Start menu.

When you go into Ubuntu for the first time after installing it, update all the software packages it was distributed with:

sudo apt update && sudo apt upgrade -y

Install Lynx browser

If you have not already done so recently, update your existing packages:

sudo apt update && sudo apt upgrade -y

Install Lynx browser:

sudo apt install -y lynx

Launch Lynx from the command line:

lynx

Various keys are available in Lynx browser to help you navigate the web, including these basic ones:

  • g – go to a new URL
  • Tab – Move between the links on this page
  • /<string> (without the angle brackets) – search for <string> on this page
  • Spacebar – Page down
  • Right arrow or Enter – Follow this link
  • Left arrow – back one page
  • q – quit Lynx browser
